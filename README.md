Turkey Run — a side-scrolling turkey escape game. Outrun the farmer through the farmyard, the barn and the kitchen: jump fences, hay bales and crates, slide under gates and beams, dodge the oven and falling carving knives, grab corn for points, and reach the treeline 1500 m away. Three lives, a farmer who closes in on every hit, and a HUD with score, distance, lives and the farmer gap. Title screen, pause, and caught/escaped end screens with restart. Keyboard and mouse/touch, synthesized WebAudio sound, no network — plain static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or build the hand-in output with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
